# QTA 录音转 MP3

iPad/iPhone 语音备忘录导出的 `.qta` 文件（本质是多轨 MOV/MP4 容器）没法直接当音频播放或分享，每次都要手动用 FFmpeg 转一遍，所以写了这个批量转换的小网页。

- 形态：Python 命令行（Flask 本地网页）
- 状态：已停
- 最后改动：2026-03-21

## 怎么用

```bash
pip install -r requirements.txt
python3 app.py
```

启动后自动打开浏览器（`http://127.0.0.1:5001`）。把文件夹或 `.qta` 文件拖进页面，或点「选择文件夹 / 选择文件」；网页读不到磁盘绝对路径，文件会先上传到本机的临时目录再转换。也可以在「手动输入路径」里按老办法扫描本机目录。

## 依赖

- Python 3 + `Flask==3.0.0`
- FFmpeg 需要预先安装（`brew install ffmpeg`），且要在 PATH 里

## 风险与边界

- 上传模式下，生成的 MP3 在系统临时目录里，不在你拖入的原文件夹旁边；工具在下一次扫描/上传前会清空上一次的临时目录，转完的文件记得及时下载或另存，别指望它一直留着。
- `.qta` 容器里通常有两条音轨：一条可解码的 AAC 立体声、一条苹果空间音频（apac）。FFmpeg 无法直接转 apac 轨，工具固定选第一条音频轨（`-map 0:a:0`），如果你的录音空间音频轨才是想要的内容，这个工具帮不上忙。
- 已知问题：早期反馈过网页端「转换后文件看起来没变化」，多半是没注意到输出在临时目录而不是原文件夹；如果重新踩到这个坑，先查 `/api/status` 返回的 `output_path`，别急着怀疑转换失败。
- 单用户本地工具，没有鉴权，不要部署到公网；上传体积上限设了 8GiB，纯本地工具向，没做额外防护。
