# 视频批量改名

一批 MP4 文件名字很随意（IMG_xxxx 之类），想批量改成「前缀 + 实际时长」这种一眼就知道内容多长的命名，一个个改太麻烦，所以写了这个脚本。

- 形态：Python 命令行
- 状态：已停
- 最后改动：2026-03-07

> **风险提示**：这个脚本会直接重命名（覆盖式地改名）磁盘上的文件。默认是 DRY_RUN，只打印「会改成什么样」的清单，不会真的动手；确认没问题后加 `--apply` 才会真正执行。

## 怎么用

```bash
python3 batch_rename.py --dir /path/to/videos --prefix "my_video_"
# 确认打印出来的重命名清单没问题后：
python3 batch_rename.py --dir /path/to/videos --prefix "my_video_" --apply
```

会把目标文件夹下的 `.mp4` 文件改名为 `{前缀}{时长}.mp4`，如 `my_video_2m8s.mp4`。

## 依赖

- Python 3
- 系统需要装好 `ffmpeg`（脚本用 `ffprobe` 读时长）

## 风险与边界

- 直接原地重命名，没有备份机制；虽然默认 DRY_RUN 不会误伤，但 `--apply` 之后如果目标文件名已存在会跳过（不会覆盖），除此之外没有回滚手段，建议先在测试文件夹跑一遍。
- 只按文件名去重（新名字已存在就跳过），不检查内容是否真的重复。
- 没有递归子目录，只处理指定文件夹下第一层的 `.mp4` 文件。
