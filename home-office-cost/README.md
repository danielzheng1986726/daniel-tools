# 在家办公成本计算器

在家办公不是零成本的：电脑手机的折旧、软件订阅、宽带、杂项行政开支，摊到每个项目头上到底是多少钱，脑子里估算不靠谱，所以写了这个脚本生成一份现成的 Excel 计算表。

- 形态：Python 命令行（生成 Excel 文件）
- 状态：已停
- 最后改动：2026-03-07

## 怎么用

```bash
pip install -r requirements.txt
python home_office_cost_calculator.py
```

会在当前目录生成 `home_office_cost_calculator.xlsx`。打开后按自己的实际情况改各项数值（设备原价、预计使用月数、业务使用比例、软件订阅费、宽带月费、行政预算、每月项目数），Excel 里的公式会自动重新计算月度总成本和单个项目的分摊成本。

## 依赖

- Python 3
- `openpyxl`

## 风险与边界

- 只是生成一份带公式的空白表格，不涉及删改已有文件，重复运行会直接覆盖同名 `.xlsx`（注意提前另存有数据的版本）。
- 折旧按直线折旧法算，业务使用比例、每月项目数这些都是估算参数，不是精确会计口径，别拿来做正式报税/财务用途。
- 表格里的数值（设备原价、软件费用等）都是示例占位，不代表 Daniel 的真实开支。
