# 公众号文字封面

公众号封面要么找图要么等 AI 生图人工挑一张，太麻烦，所以写了这个纯排版的文字封面生成器：同样的标题永远生成同样的图，不用人眼审。

- 形态：Python 命令行
- 状态：在用
- 最后改动：2026-09-19

## 怎么用

```bash
python3 make_cover.py --title "最会踩刹车的人，把 AI 推得最快" -o cover.png
```

带栏目名和落款：

```bash
python3 make_cover.py --title "标题" --kicker "播客手记" --brand "示例公众号" --square-too
```

常用参数：
- `--title`：标题文字，`\n` 可强制换行。
- `--kicker` / `--brand`：标题上方小字 / 左下角落款，都可选。
- `--theme plain|dark`：配色主题。
- `--safe-zone thumb|strict|none`：安全区宽度，默认 `thumb`（只保 1:1 转发卡片不截字，微信封面面板只有 2.35:1 和 1:1 两个展示位）。
- `--square-too`：额外出一张 1149x1149 的小图。
- `--contact-sheet`：额外出一张裁剪验证图，把常见发布工具会裁的三个比例（16:9 / 1:1 / 3:4）并排画出来，肉眼确认没截字。
- `--font /path/to/font.ttc`：指定中文字体文件，见下面「依赖」。

## 依赖

```bash
pip install pillow
```

需要一个支持中文的字体文件（`.ttf` 或 `.ttc`），按下面优先级找：
1. `--font` 命令行参数
2. 环境变量 `COVER_FONT_PATH`
3. 自动探测常见系统字体：macOS 的 Hiragino Sans GB / STHeiti，Linux 的 Noto Sans CJK / 文泉驿

三个都没有会直接报错并提示怎么指定。Linux 上没有中文字体的话，装一个 Noto Sans CJK 通常最省事：`apt install fonts-noto-cjk`。

字重说明：脚本假设字体是"一个文件里含多个字重"的合集字体（比如 Hiragino Sans GB.ttc），用 font index 切换粗细；如果你给的是单一字重的 `.ttf`，粗体会自动退回常规体渲染，不会报错，但标题不会加粗。

## 风险与边界

不联网、不调用任何外部 API，纯本地渲染，不删改任何已有文件（只写输出路径）。

安全区参数是针对一个具体的第三方发布工具（MultiPost）的居中裁剪逻辑算出来的：`--safe-zone` 的默认值假设最终发布走公众号后台的封面面板（只有 2.35:1 和 1:1 两个展示位）。如果你用别的发布路径，裁剪比例可能不一样，建议先用 `--contact-sheet` 出图肉眼核对一遍。

标题排太长会自动换行、最多 3 行，排不下会在 stderr 打警告，不会截断文字——看到警告就把标题改短。
