# 照片去重

手机导出的照片散在好几个文件夹里，微信保存一份、下载一份、相册再导出一份，内容一样但文件名全不一样，手动比对太麻烦，所以写了这个。

- 形态：Python 命令行（Flask 本地网页）
- 状态：已停
- 最后改动：2026-03-07

> **风险提示**：这个工具会真的删除或移动你磁盘上的文件。默认 `DRY_RUN=1`，`/api/execute` 只返回「将要做什么」的清单，不会真的动手；网页上点「执行操作」也还有一次确认弹窗。想让它真正执行，需要显式设置 `DRY_RUN=0` 再启动。

## 怎么用

```bash
pip install flask flask-cors
python app.py
```

浏览器打开 `http://127.0.0.1:5001`，在页面输入源目录路径，点「开始扫描」。工具按文件内容（MD5）找重复图片，可选「扁平化预览」把唯一文件按年/月归档到新目录。确认清单没问题后点「执行操作」。

先用 `tests/generate_test_data.py` 生成一批假测试数据，别直接拿真实照片库练手：

```bash
cd tests
mkdir source_photos   # 放 6-10 张随便什么照片
python3 generate_test_data.py
# 生成结果在 ./test_photos/，用它去测试 app.py 的扫描逻辑
```

## 依赖

- Python 3
- `flask`、`flask-cors`

## 风险与边界

- 会真的删除/改写磁盘上的文件，见上面的风险提示。
- 去重基于内容哈希（MD5），同名不同内容的文件不会被误删；但 MD5 理论上存在碰撞风险，重要照片建议先备份再跑。
- 只扫描图片扩展名（jpg/jpeg/png/gif/webp/bmp），忽略视频等其他格式。
- 单用户本地工具，没有鉴权，不要部署到公网。
