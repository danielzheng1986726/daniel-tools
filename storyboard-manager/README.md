# 分镜管理

做 AI 视频项目要管理一堆镜头：每个镜头的画面描述、运镜、服装分配、Prompt……全靠一份 Excel 或聊天记录记着太乱，给客户看又不能把内部 Prompt 全漏出去，所以写了这个本地分镜管理小工具。

- 形态：网页（React + Vite，本地跑，数据存浏览器 IndexedDB）
- 状态：已停（已被后来的视频业务工作台取代）
- 最后改动：2026-03-07

## 怎么用

```bash
npm install
npm run dev
```

启动后浏览器访问 `http://localhost:5173`。首页可以新建项目，也可以点「加载演示项目」看一个现成的示例分镜（虚构的「奇幻世界 AI 时装秀」，17 镜头）。

### 「人工桥梁」导入流程

因为这是纯前端工具，没接 LLM API，镜头内容本来是配合 Claude 对话手工搬运的：

1. 在对话里让 AI 输出符合工具约定格式的项目 JSON（字段说明见 `src/utils/briefSchema.js`）。
2. 复制 JSON，在 app 里点「从 JSON 导入」粘贴，自动生成整套分镜卡片。

### 核心功能

- 多项目管理（新建/导入/删除），镜头拖拽排序
- 每个镜头可上传参考图片/运镜视频
- 内部视图（含 Prompt、服装分配、过时检测）和客户视图（隐藏内部信息的干净布局）两套展示
- 导出 JSON 备份，或导出 PDF（客户版/内部版）

## 依赖

- Node.js + npm
- Vite 5、React 18、Tailwind CSS 3、`@dnd-kit`（拖拽）、`idb`（IndexedDB 封装）、`jspdf` + `html2canvas`（导出 PDF）

## 风险与边界

- 数据全部存在浏览器 IndexedDB 里，换浏览器/清缓存/换设备都会丢，没有做云端同步或导出提醒；重要项目记得手动导出 JSON 备份。
- 纯本地工具，没有账号体系和权限控制，「客户视图」只是隐藏了字段，不是真正的访问权限隔离；如果要真给客户看，导出 PDF 更安全。
- JSON 导入没有做严格的 schema 校验，格式不对可能导入出半成品分镜，建议先小范围试。
