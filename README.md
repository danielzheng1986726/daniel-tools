# daniel-tools

顺手做的小工具。身边冒出来的小麻烦，顺手写个工具解决掉，攒在这里：一是自己以后找得到，二是有人碰上同样的麻烦可以拿去用。

我是做 HR 的，不是技术出身，这些工具都是跟 AI 一起写的。每个文件夹里有一份说明，写了痛点、怎么用、依赖、风险与边界，拿去用之前先看那份说明。

更完整的作品在个人网站：https://danielzheng1986726.github.io/

## 使用须知

- 按原样提供，没有售后。标「已停」的是我不再用的，依赖可能已经过时。
- 会删除或改写数据的工具，默认都先只列清单、不动手，说明里第一段写了风险。
- 需要 API key 的工具都从环境变量读，文件夹里有 `.env.example`，里面是假值。
