# 分析原则与质量标准

## 核心原则

### 1. 张力优先于平衡

传统的"平衡分析"追求的是让双方看起来各有道理。这不是我们的目标。我们追求的是真正的张力——让双方的论证都锋利到不可忽视，然后让读者看清这种锋利之间的碰撞。

好的分析让人不舒服，因为它不提供简单的答案。坏的分析让人舒服，因为它告诉你"双方都有道理"然后就结束了。

### 2. 具体性是可信度的基础

每一个论点都应该具体到可以被反驳。如果一个论点模糊到没有人能反对它，它就没有信息量。

反面示例："我们应该综合考虑各方面因素"——谁会反对这个？
正面示例："在人均 GDP 低于 1 万美元的经济体中，经济增长的优先级应该高于环境保护"——这可以被反驳，因此它有价值。

### 3. 诚实面对不确定性

如果一个问题确实没有明确答案，说"在现有信息下无法判断"比硬给一个结论要好。条件性判断框架的价值就在于此——它不告诉你答案，而是告诉你在什么条件下答案会不同。

### 4. 避免常见的分析陷阱

**假平衡陷阱**：不是所有争议的双方都同样有道理。如果一方的论证确实远强于另一方，审计员应该如实说。

**复杂性逃避陷阱**：不能用"这是一个复杂问题"来代替分析。复杂问题需要的是更精细的分析，不是更模糊的结论。

**锚定效应陷阱**：这是整个 Agent Teams 架构要解决的核心问题。两个辩护者在独立上下文中工作，就是为了避免一方的论证锚定另一方。Lead Agent 在综合时也要警惕自己被先看到的一方锚定。

**道德高地陷阱**：有些立场天然占据道德高地（环保、人权、儿童保护等），但这不意味着这些立场的具体论证就不需要检验。审计员需要对所有立场的逻辑质量一视同仁。

## 质量检查清单

### 对辩护者的检查

- [ ] 是否有至少 2 个具体论据（案例、数据、逻辑推演），而不是纯粹的立场声明
- [ ] 是否诚实地标明了自己立场成立的前提条件
- [ ] 在交叉质疑中，是否攻击了对方的最强论点而非稻草人
- [ ] 是否存在偷换概念或逻辑滑坡

### 对审计员的检查

- [ ] 是否揭示了至少一个双方都没意识到的隐含假设
- [ ] 分歧本质的诊断是否准确（价值观冲突 vs 事实分歧 vs 预测分歧 vs 定义分歧）
- [ ] 条件性判断框架是否具体到可以用于实际决策
- [ ] 篇幅分配是否对两方公平（除非一方论证确实更弱，需要更多篇幅解释为什么）

### 对最终产出的检查

- [ ] 读完后，读者是否能清晰复述双方各自最强的论证
- [ ] 读者是否能说出分歧的根源是什么
- [ ] 读者是否得到了一个"在什么条件下如何判断"的实用框架
- [ ] 产出是否避免了"各打五十大板"的感觉
- [ ] 每方核心论证中是否包含至少一处对对方最强攻击的正面回应（对抗痕迹）
- [ ] 总篇幅是否控制在 2000-3000 字（可根据复杂度调整）

## 议题适用性判断

不是所有争议都适合用这个团队分析。以下情况适合：

**适合**：
- 涉及真正的价值观冲突（如效率 vs 公平）
- 涉及事实不确定性下的政策选择
- 涉及短期利益与长期影响的权衡
- 涉及不同利益相关方的立场冲突

**不适合**：
- 有明确正确答案的事实性问题（"地球是不是圆的"）
- 纯粹的个人偏好问题（"咖啡还是茶"）
- 涉及基本人权或儿童安全的议题（某些底线不需要辩论）
- 信息严重不对称的议题（一方有大量未公开信息，辩论没有意义）

如果 Lead Agent 判断议题不适合，应向用户说明原因并建议替代分析方式。
