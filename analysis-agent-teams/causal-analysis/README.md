# 系统性因果分析团队（Causal Analysis Team）

> Agent Teams 分析线第二个项目。
> 用认知多样性架构，替代单 Agent 的同质化原因清单。

---

## 解决什么问题

单 Agent 做因果分析时有一个隐蔽缺陷：它列出第一个原因后，后续原因会不自觉围绕第一个原因的认知框架展开。清单看似全面，实则同质——都是同一类解释的变体。

本团队用两个 Agent 从不同认知入口切入，确保原因清单的真正多样性。

---

## 团队角色

| 角色 | 职责 |
|------|------|
| 主流解释者 | 从最显而易见、最有共识的方向构建因果解释 |
| 边缘探索者 | 刻意绕开前三个最显而易见的解释，专找非常规、跨学科、反直觉的因果路径 |
| Lead Agent | 合并去重、交叉验证、评估排序、生成最终报告 |

## 与争议分析团队的区别

争议分析团队的核心是**对抗**——两个辩护者为对立立场辩护，张力产生洞察。

因果分析团队的核心是**互补**——两个分析者从不同认知入口切入同一个问题，多样性产生完整性。不需要交叉质疑，需要的是交叉验证（一方提出的原因，另一方是否能找到支持或反驳的证据）。
