# 研究报告审计团队（Research Audit Team）

> Agent Teams 分析线第三个项目。
> 合并改造自原 Prompt #二.1（研究报告批判性审视）和 #二.6（市场预测可信度审计）。
> 用竞争性假设架构，替代单 Agent 的线性六步审查。

---

## 解决什么问题

原 Prompt 让单 Agent 按 1→2→3→4→5→6 的顺序审查研究报告。问题是：如果 Agent 在第 1 步（数据来源）就形成了负面判断，后续所有步骤都会被这个判断锚定——它会不自觉地到处找证据来"确认"第 1 步的结论。

本团队打破线性，让两个 Agent 从对立的预设出发并行审查同一份材料。

---

## 团队角色

| 角色 | 预设立场 | 职责 |
|------|----------|------|
| 魔鬼代言人 | 假设报告有问题 | 专找数据漏洞、方法论缺陷、逻辑跳跃、利益冲突 |
| 善意诠释者 | 假设研究者诚实 | 在现有数据约束下，得出最合理的结论；找到报告的真正价值 |
| Lead Agent | 无预设 | 综合两份审查，生成对比报告和可信度评估 |

---

## 核心设计：从任意环节突破

魔鬼代言人不必按 1-2-3-4-5-6 的顺序审查。它可以从它觉得最可疑的环节开始攻击——这种"从最弱环节突破"的策略在单 Agent 线性流程里做不到。

善意诠释者也不按固定顺序。它优先找到报告中证据最扎实的部分，从那里构建对研究者最有利的解读。

cd research-audit-team

直接说：

```
请审计以下研究报告/市场预测：[粘贴内容或描述]
```

或使用模板：

```
请读取 templates/audit-brief.md
```
