# 战略竞争力诊断团队（VRIO × Porter Five Forces）

> Agent Teams 分析线第四个项目。
> 改造自原 Prompt #三.12。
> 用内外独立分析 + 错位诊断架构，替代单 Agent 的内外分析自动对齐。

---

## 解决什么问题

原 Prompt 让单 Agent 先做 VRIO 内部资源分析，再做五力外部竞争分析。问题是：做完 VRIO 后，Agent 在做五力时会不自觉地让外部分析"配合"内部结论——如果 VRIO 认为专利是持久优势，五力分析就会低估替代品威胁。两份本应独立的分析在同一个上下文窗口里被"对齐"了。

本团队让两个 Agent 在完全独立的上下文中分别做内部和外部分析。错位本身就是最有价值的战略洞察。

---

## 团队角色

| 角色 | 职责 | 不做什么 |
|------|------|----------|
| 内部资源审计师 | 只做 VRIO 四维评估 | 不考虑行业竞争格局 |
| 行业竞争分析师 | 只做 Porter 五力分析 | 不考虑公司具体资源 |
| 战略诊断师（Lead） | 做叠加映射，找两份报告间的错位 | 不重做 VRIO 或五力 |

## 核心价值：错位洞察

举例：如果内部资源审计师认为"自研算法是持久竞争优势（V✓R✓I✓O✓）"，但行业竞争分析师独立发现"替代品威胁强——开源模型正在快速逼近商业模型的性能"，这个错位就揭示了一个关键战略风险：公司认为是护城河的东西，从外部看正在被侵蚀。

单 Agent 几乎不可能产出这种错位，因为它在同一个窗口里会自动调和矛盾。
