# 数据标准与信息溯源规范

## 可接受的数据来源

| 优先级 | 来源类型 | 示例 |
|--------|----------|------|
| 最高 | 公司官方披露 | 年报/10-K、招股书、官方新闻稿 |
| 高 | 政府/监管机构 | 国家知识产权局、证监会、行业主管部门 |
| 高 | 权威行业报告 | Gartner、IDC、McKinsey、BCG、中国信通院 |
| 中 | 主流财经媒体 | Bloomberg、Reuters、财新、36氪 |
| 中 | 学术论文 | 经同行评审的期刊论文 |
| 低 | 行业观察/分析 | 个人博客、社交媒体、未经验证的行业传闻 |

## 标注格式

每条关键数据后附：[来源名称, 发布日期/年份]

如果来源有可访问链接，一并附上。

## 无数据时的处理

- 标注"暂无公开信息"
- 如果可以基于相关信息做合理推断，标注"基于[什么信息]推断，待验证"
- 绝不编造具体数字

## 外文资料

引用外文资料时，提供中文摘要（1-2 句），确保非英文读者也能理解要点。

## 数据时效性

- 财务数据优先使用最近一个完整财年的数据
- 行业数据优先使用最近 1-2 年的报告
- 如果只能找到较老的数据，标注年份并说明"更新数据待查"
